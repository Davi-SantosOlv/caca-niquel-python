# 🎰 Simulador de Caça-Níquel em Python

Meu primeiro projeto em Python! Este programa simula o funcionamento de uma máquina de caça-níquel. Desenvolvê-lo me permitiu praticar conceitos fundamentais da linguagem de forma interativa.

## 📚 Conceitos praticados

Durante o desenvolvimento, tive meu primeiro contato com:

- **Lists (listas):** organização de coleções de elementos.
- **Sets (conjuntos):** armazenamento de elementos únicos.
- **Dictionaries (dicionários):** organização de informações em pares de chave e valor.

## 🚀 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Davi-SantosOlv/caca-niquel-python.git
   ```
3. Entre na pasta do projeto e execute:
   ```bash
   python main.py
   ```

## 🎯 Objetivo

Praticar os fundamentos de Python por meio de um projeto simples, desenvolvendo a lógica de programação e explorando diferentes estruturas de dados.
